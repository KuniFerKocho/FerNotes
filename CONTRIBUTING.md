# Contributing

Thanks for your interest in contributing to FerNotes! To keep contributions smooth and useful, please follow these steps:

1. Fork the repository and create a feature branch: git checkout -b my-feature
2. Make small, focused changes and add tests if applicable
3. Open a pull request describing the change and linking any related issue

Guidelines
- Write clear commit messages
- Keep PRs small and focused
- Be responsive to review comments

Code of Conduct
Please follow the project's Code of Conduct: CODE_OF_CONDUCT.md
