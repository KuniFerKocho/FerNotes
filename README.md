# FerNotes

A small, local-first note and drawing app built with Tkinter. Save files with the custom `.fernotes` JSON format.

Features
- Draw with selectable colors and pen size
- Eraser and text mode
- Undo/redo
- Save/open .fernotes files

Requirements
- Python 3.8+
- Pillow

Install

```bash
pip install -r requirements.txt
```

Run

```bash
python3 fernotes.py
```
